📌 Propiedades clave:

flex-wrap: wrap; → Permite que los elementos bajen a una nueva línea
gap: 15px; → Espacio entre elementos (mejor que usar margin)
width: 200px; → Ancho fijo, se acomodan automáticamente

Prueba: Cambia el tamaño de la ventana para ver cómo los elementos se reorganizan automáticamente.
